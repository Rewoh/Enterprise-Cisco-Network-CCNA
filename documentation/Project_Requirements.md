# Enterprise Cisco Network Project

## Project Overview

This project demonstrates the design, implementation, configuration, testing, and documentation of a secure enterprise network using Cisco Packet Tracer. The implementation follows Cisco CCNA networking principles and industry best practices in routing, switching, network segmentation, IP addressing, and network security.

The project has been developed as a portfolio to demonstrate practical networking knowledge, configuration skills, technical documentation, and troubleshooting abilities expected of an entry-level Network Engineer, Systems Administrator, or IT Support Engineer.

---

# Business Scenario

ABC Technology Solutions Ltd. is a medium-sized technology company located in Yaoundé, Cameroon. The company has recently expanded into a new office building and requires a secure, scalable, and well-documented network infrastructure to support its daily operations.

The organization consists of multiple departments including Administration, Finance, Human Resources, Sales, Customer Support, Information Technology, Executive Management, and a centralized Server Room.

The company requires a modern enterprise network capable of supporting secure communication between departments while protecting confidential information through proper network segmentation and security policies.

---

# Project Objectives

The objectives of this project are to:

- Design a scalable enterprise network.
- Segment departments using Virtual Local Area Networks (VLANs).
- Configure routing between VLANs.
- Implement dynamic IP address allocation.
- Secure network devices using SSH.
- Configure network address translation (NAT).
- Implement Access Control Lists (ACLs).
- Configure dynamic routing using OSPF.
- Secure switch ports.
- Produce complete technical documentation.
- Demonstrate professional network engineering practices.

---

# Scope of the Project

The project includes:

- Enterprise network design

- VLAN implementation

- OSPF routing

# Expected Outcome

Upon completion, the enterprise network will provide secure communication between departments, centralized network management, automated IP address assignment, secure remote administration, controlled Internet access, and a scalable architecture suitable for future expansion.
