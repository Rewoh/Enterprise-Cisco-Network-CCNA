# Enterprise Cisco Network (CCNA Portfolio Project)

## Overview

This repository contains the design, implementation, configuration, documentation, and verification of a segmented enterprise network developed using Cisco Packet Tracer.

The project demonstrates practical networking skills aligned with Cisco Certified Network Associate (CCNA) technologies and best practices.

---

## Objectives

- Design a scalable enterprise network
- Configure Cisco routers and switches
- Implement VLAN segmentation
- Configure inter-VLAN routing
- Configure DHCP
- Configure NAT/PAT
- Configure SSH remote access
- Configure OSPF routing
- Implement ACL security
- Configure switch security
- Perform troubleshooting
- Document every stage professionally
